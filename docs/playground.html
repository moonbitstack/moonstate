The records

Every row is a checkpoint the saver holds: the state as merged, the tasks the next superstep would run, and whether the run is waiting. Picking one reads it; the ring marks it.

    The record itself

    What a Saver hands back, as it hands it back — the same bytes a database row or a browser store would hold.

    What to try

    • a question — run it: the ring stops partway and wants a number.
    • pull the plug — at that stop, reload: the question is still there.
    • a fan-out — three shards add one each; the log keeps their order.
    • rewrite the tail — on a line, run to the end, then rewrite.
    • ◀ ▶ — walk the checkpoints without running anything.

    The engine on this page is the library itself, compiled to JavaScript. The records live in this browser, which is why a reload can continue a run.
